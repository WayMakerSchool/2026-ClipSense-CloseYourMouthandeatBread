# 2026-10-19 웹 연결 작업 기록

## 구현

- 웹 원본: `web_clip/index.html`, `web_clip/app.js`, `web_clip/style.css`.
- 로컬 서버: `clip_web.py`. 접속: `http://127.0.0.1:5173`.
- 보드 없는 연습 실행: `.venv/bin/python scripts/run_web_demo.py`.
  합성 빨강/초록/신호 없음이 각 12초씩 순환한다. `--scene`으로 한 장면 고정 가능.
- 클립 대상: 사용자가 알려준 `http://192.168.0.52`.
- 기존 HSV·형태 판독과 엄격 판단 재사용, Flutter 자동 웹 변환 아님.
- 실제 API·남은 시간은 연결하지 않았으므로 최종 안내는 대기/확인 불가.
- 사진 출처/신선도 표시, 한국어 음성, 장면별 결과·기기/브라우저·음성 이벤트 JSON 내보내기.

## 현장에서 남겨야 할 것

- 실제 기기·브라우저명/버전, Wi-Fi·HTTP·인증·허용 접속 조건.
- 클립 촬영 출처 확인과 움직임→웹 갱신 연속 영상.
- 빨강/초록/신호 없음 각각의 정답·판독·최종 안내 결과 기록.
- 소리를 포함한 안내 영상, 재실행 후 사진·화면·음성 비교.
- 두 학생이 직접 설명한 입력→판독→판단→안내 흐름.

## 보드 없는 합성 입력 결과

기존 기준을 고정하고 새 프레임 9장을 각각 입력한 자동 검증이다. 실제 신호등 촬영
결과가 아니다. 원본 해시·고정 기준은 `scratchpad/web-2026-10-19/scene-results.json`에 있다.

| SIM 입력 | 프레임 판독 | 연속 확정 | 최종 결정 | 안내 문구 |
|---|---|---|---|---|
| 빨강 원 | RED | RED | WAIT | 빨간불로 판독했습니다. 기다리세요. |
| 초록 원 | GREEN | GREEN | WAIT | 초록불로 판독했습니다. 실제 남은 시간을 확인할 수 없습니다. 기다리세요. |
| 회색 배경·신호 없음 | NONE | UNKNOWN | UNKNOWN | 신호를 확인할 수 없습니다. 기다리세요. |

브라우저 음성 시작/종료 이벤트를 확인했고, 사용자가 SIM 시연의 실제 소리가 들린다고
확인했다. 위 세 문구를 각각 모두 들었는지, 재실행 후에도 들리는지는 아직 확인하지 않았다.

위 현장 항목이 남아 있으므로 오늘 세 항목을 **완료로 표시하지 않는다**.
사용 순서와 고정 기준은 `web_clip/README.md` 참고.

보드 없는 브라우저 확인 자료(로컬, SIM 전용):

- `scratchpad/web-2026-10-19/sim-browser.png`: SIM 표시가 있는 웹 화면.
- `scratchpad/web-2026-10-19/sim-browser-evidence.json`: Chrome에서 내려받은 세 색상
  프레임/판독·음성 이벤트 기록. 내려받을 당시 화면의 청취 확인 버튼 기록은 0회다.
  이후 사용자 채팅으로 실제 소리를 확인했으며, 기존 JSON의 이벤트는 소급 수정하지 않는다.
  실제 보드 검증 자료가 아니다.
