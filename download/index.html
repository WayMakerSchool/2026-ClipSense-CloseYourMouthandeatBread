ClipSense 안드로이드 시연 앱

휴대폰 카메라로 보행신호등을 읽고, 신호 데이터와 둘 다 초록일 때만 "지금 건너셔도 됩니다"라고 안내합니다.

APK 다운로드 (25.8MB, Android 64비트)

시연용 빌드입니다. 신호 데이터는 실제 서울 신호가 아닌 시연값(초록 30초 → 빨강 20초 반복)이며 화면에 "시연 데이터"가 표시됩니다. 실제 보행 판단에 사용하지 마세요.

설치

  1. 안드로이드 휴대폰 Chrome에서 위 버튼으로 다운로드
  2. "출처를 알 수 없는 앱 설치"를 허용
  3. 앱 실행 → 카메라·위치 권한 허용 → 교차로·방향 선택 → 화면 탭으로 시작
